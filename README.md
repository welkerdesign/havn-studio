# HAVN testing site

Static publication of the HAVN mobile design explorer. The browser renders the interactive vehicle locally; Unreal presentation views are rendered images.

This is an independent, unofficial design study. Geometry is based on the supplied photo-informed model. Pricing is a dated research snapshot, not a live quote. The site does not collect orders or contact a manufacturer.

This repository contains the generated testing site and its public assets. Source development and the Unreal project are maintained separately. Third-party environment provenance is included in `environments/LICENSE.md`; Three.js licensing is in `licenses/THREE-LICENSE.txt`.
