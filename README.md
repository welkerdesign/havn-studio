# HAVN testing site

Live testing site: [HAVN Build Studio](https://welkerdesign.github.io/havn-studio/).

Live Unreal is the primary 360-degree renderer. Doors, the Murphy bed, seating, lights, finishes, equipment and the AMG-style grille run in Unreal, with Studio, Desert and Fall scenes. The browser model loads automatically if the stream cannot connect or stays too slow, preserving the build settings. The shared Unreal session requires the separate HAVN GPU host to remain running.

The V26 cab-over revision adds a photo-derived air gap above the cab while preserving the front fascia thickness. Its estimated 65 mm forward clearance is a visualization assumption, not a factory measurement.

This is an independent, unofficial design study. Geometry is based on the supplied photo-informed model. Pricing is a dated research snapshot, not a live quote. The site does not collect orders or contact a manufacturer.

This repository contains the generated testing site and its public assets. Source development and the Unreal project are maintained separately.
