# HAVN testing site

Live testing site: [HAVN Build Studio](https://welkerdesign.github.io/havn-studio/).

The interface supports a live Unreal Engine 360-degree stream, a local browser configuration preview, and Unreal studio images. The live stream requires the separate HAVN GPU host to remain running. The shared studio session supports orbit, zoom, and exterior camera presets; configuration and cabin controls open Explore 3D.

This is an independent, unofficial design study. Geometry is based on the supplied photo-informed model. Pricing is a dated research snapshot, not a live quote. The site does not collect orders or contact a manufacturer.

This repository contains the generated testing site and its public assets. Source development and the Unreal project are maintained separately. Third-party environment provenance is included in `environments/LICENSE.md`; Three.js licensing is in `licenses/THREE-LICENSE.txt`; Pixel Streaming licensing is in `licenses/PIXEL-STREAMING-LICENSE.md`.
