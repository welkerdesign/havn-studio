# HAVN testing site

Live testing site: [HAVN Build Studio](https://welkerdesign.github.io/havn-studio/).

Live Unreal is the primary 360-degree renderer. Doors, the Murphy bed, seating, lights, finishes, equipment and the AMG-style grille run in Unreal, with Studio, Desert and Fall scenes. The browser model loads automatically if the stream cannot connect or stays too slow, preserving build settings. The shared Unreal session requires the separate HAVN GPU host to remain running.

V28 refines the Sprinter grille, fenders, bumper junction and lower door cladding. Desert and Fall daylight include broad fill lighting. Headlights and fog lamps have paired switches, upper clearance lights illuminate together, and the galley exterior fixture offers Off, White LED and Amber modes. Existing saved light settings migrate automatically. The V27 flat cab-over underside, photo-derived roof air gap, wide attic flap and continuous interior finishes remain.

This is an independent, unofficial design study, based on photographs and the supplied model rather than factory CAD. Pricing is a dated research snapshot. The site does not collect orders or contact a manufacturer.

This repository contains the generated testing site and public assets. Source development and the Unreal project are maintained separately.
