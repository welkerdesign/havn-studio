# HAVN testing site

Live testing site: [HAVN Build Studio](https://welkerdesign.github.io/havn-studio/).

Three.js loads automatically when the page opens, without contacting or starting the Unreal GPU host. Use the side switch to start Unreal when wanted, or return to Three.js at any time, including while Unreal is starting or connecting. Three.js preserves build settings and stays selected until you choose Unreal again. Returning to Unreal starts a fresh host session. Automatic fallback and recovery still apply when Unreal is selected. Doors, the Murphy bed, seating, lights, finishes, equipment and the AMG-style grille run in both viewers, with Studio, Desert and Fall scenes. The shared Unreal session requires the separate HAVN GPU host to remain running.

V29 reshapes the front fender corner, adds prominent bonnet vents and tubular cab steps, and refines the rounded corner bathroom sink. Driver water fill, refrigerator vent, toilet access and passenger outdoor shower fittings follow owner references. The rear bumper has a plate recess, hitch, mirrored angled brake/reverse lenses and separately switched square work lights. Reverse lenses are decorative and unlit. The entry porch fixture is removed. The awning edge stays dimmable folded or extended; seven lower locker doors hang down through 180 degrees, while the passenger aft locker retains its straight-out opening. The attic flap lifts inward with checked roof clearance.

This is an independent, unofficial design study, based on photographs and the supplied model rather than factory CAD. Pricing is a dated research snapshot. The site does not collect orders or contact a manufacturer.

The Ridgeline MAX/Mojab package was withdrawn at the owner's request. The existing Owl ADAX catalog option remains available. Payload-tracking groundwork retains the owner's approximate 1,800 lb post-build allowance; it does not yet establish vehicle weight or safe remaining payload.

Equipment > Front bumper now offers two independent Baja Designs LP4 pairs for the Owl ADAX: inner white/clear and outer amber. Selecting a pair selects the Owl bumper; changing bumper removes both. Both pairs appear amber–clear–clear–amber in front view. Each pair adds a separately listed $875.95 parts estimate and 5.6 lb of lamps (two at 2.8 lb); additional wiring and mounting mass remain unknown. Living > Lighting includes separate lens-glow switches. LP4-fitted builds currently preview in Three.js; the native Unreal scene has not yet been updated for these lamps. Mounts are a visual study, not validated fitment or road-beam photometry.

This repository contains the generated testing site and public assets. Source development and the Unreal project are maintained separately.
